# Student Task Manager

## Description

Student Task Manager is a simple web application developed using HTML, CSS, and JavaScript. It allows students to enter their name and add tasks that they need to complete.

## Features

- Enter student name
- Add tasks
- Display multiple tasks
- Simple and clean user interface
- Interactive task management using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
